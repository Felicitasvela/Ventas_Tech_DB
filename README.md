# RetailPro - Proyecto de Data Analytics

## Descripción

RetailPro es un proyecto de Data Analytics orientado al análisis del desempeño comercial de una empresa. El objetivo es transformar los datos de ventas en información útil para facilitar la toma de decisiones.

El proyecto trabaja con información de ventas, clientes, productos, categorías, territorios y canales de venta.

## Objetivos del análisis

El proyecto busca responder preguntas de negocio como:

- ¿Qué productos y categorías generan mayor y menor rendimiento?
- ¿Qué territorios presentan mejores resultados?
- ¿Qué clientes tienen mayor valor para el negocio?
- ¿Cómo evolucionan las ventas a lo largo del tiempo?
- ¿Cómo se comportan los distintos canales de venta?

## Herramientas utilizadas

- **SQL Server:** creación y administración de la base de datos RetailPro.
- **SQL:** consultas, relaciones entre tablas y análisis de los datos.
- **Power BI:** proceso ETL, modelado de datos, creación de medidas DAX y visualización de resultados.
- **GitHub:** organización, almacenamiento y documentación de las distintas etapas del proyecto.

## Análisis realizados

Durante el proyecto se realizaron consultas para:

- Analizar la facturación y el ticket promedio.
- Crear rankings de productos.
- Identificar clientes recurrentes.
- Comparar períodos de ventas.
- Analizar canales y territorios.
- Relacionar las distintas tablas mediante JOIN.

## Cómo ejecutar los scripts SQL

1. Abrir SQL Server Management Studio.
2. Crear o seleccionar la base de datos `Ventas_Tech_DB`.
3. Abrir los scripts SQL del proyecto.
4. Verificar que la base seleccionada sea `Ventas_Tech_DB`.
5. Ejecutar los scripts respetando el orden en el que fueron desarrollados, ya que algunas consultas dependen de tablas o campos creados previamente.
6. Revisar los resultados obtenidos antes de continuar con el siguiente script.

## Objetivo final

El objetivo final de RetailPro es construir una solución de análisis que permita comprender el desempeño comercial e identificar oportunidades de mejora a partir de los datos.
